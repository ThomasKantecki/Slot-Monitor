# assets/

Static pieces that get inlined into every built page, so the pages work as single files.

| File | What it is |
|---|---|
| `adventhealth-logo.png`, `orlandohealth-logo.png` | The two system logos, embedded as base64 into the pages. |
| `fonts.css` | The two web fonts (JetBrains Mono and Inter) embedded as base64 CSS. Regenerate with `npm run fonts` (needs the network). |
